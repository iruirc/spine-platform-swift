---
description: |
  Bootstrap a new multi-package SPM workspace.
  Создаёт новый multi-package SPM workspace.
---

Activate `spine-platform-swift:workspace-init` with arguments: $ARGUMENTS and follow its flow. If `--from <path>` is supplied, run the batch mode. If `--resume` is supplied, run the resume mode. Otherwise, run the interactive Q&A. `--dir <path>` (any mode) makes `<path>` the workspace root — the meta repo — instead of the current folder, creating it when absent.
